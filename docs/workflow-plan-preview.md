# Workflow plan preview\n\n`previewWorkflow` validates a workflow and returns a deterministic, side-effect-free plan. It resolves explicit skills or capability/provider pairs, validates the dependency DAG, assigns stable topological layers, and reports each selected implementation's version, capabilities, requirements, and currently registered providers for those requirements.\n\nNo skill `execute` function is called while planning. Tasks in one layer have no dependency ordering between them and are candidates for later bounded parallel execution; this preview does not execute tasks or promise concurrency. Missing requirement providers are surfaced as empty provider lists for orchestration policy to handle explicitly.\n
