# Bounded workflow execution\n\n`executeWorkflow(definition, registry, { maxConcurrency })` executes dependency layers in order and runs independent tasks in bounded chunks. The default concurrency is 1 for backwards-compatible sequential behavior; accepted values are integers from 1 to 16.\n\nA chunk is awaited before another is scheduled. On failure, already-running siblings in the current chunk are awaited, no later chunk or dependency layer is scheduled, and remaining tasks are reported as skipped. Outputs are schema-validated before becoming visible to dependent tasks. Results are returned in deterministic plan order even when execution completes out of order.\n
